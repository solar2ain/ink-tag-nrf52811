# 硬件与功能说明

中文 | [English](hardware.en.md)

InkTag nRF52811 提供电子纸日历、时钟和图片展示所需的基础功能。屏幕型号和方向通过共享 WebUI 或 CLI 配置并保存。

152×152、200×200、240×240等方形及近方形尺寸使用按尺寸选择的矩形模板；控制器、配方、颜色和容量仍需匹配实际屏幕。

## 主板

| 项目 | 说明 |
| --- | --- |
| 已测主板 | EL022HWRL，设备页型号为 `nrf52811_asel22` |
| 主控 | nRF52811，192 KiB Flash、24 KiB RAM |
| 图片存储 | 512 KiB 外置 Flash，约 472 KiB 用于图片 |
| 时钟 | 32.768 kHz 低频晶振 |
| 屏幕接口 | 硬件 SPI，4 MHz；空闲时关闭屏幕电源使能 |
| 状态灯 | RGB 三色灯 |
| 蓝牙名称 | 应用 `IKT_NRF_XXXX`；Recovery `IKT_NRF_XXXX_OTA` |

EL029H2 尚未完成独立硬件验证，不能仅凭外观相似使用 EL022HWRL 的测试结论。

## 已测屏幕

| 屏幕 | 颜色与尺寸 | 已验证范围 |
| --- | --- | --- |
| 原 2.13 英寸 HEMA 屏 | 黑白红，128×250，可视 122×250 | 页面、图片、方向及屏温回读 |
| 华为 3.98 英寸 A0 | 黑白红黄，768×552 | 页面、图片、方向及颜色 |
| 华为 3.98 英寸 A1 | 黑白红黄，768×552 | 图片、方向、颜色及轮播 |

屏幕温度取决于控制器是否支持回读；A0/A1 温度适配尚未完成实板验证。其他可选配置不代表已在此主板上验证；SES 2.13/2.66 不包含在本固件中。

## 图片与设置

图片名称最多为 35 个 UTF-8 字节，在上传或替换时设置名称和类型。图槽 ID 稳定，删除后可以存在空位；实际容量以设备报告为准。

单个图槽大小包含图片、名称等元数据及对齐空间。RLE 压缩传输数据，图槽仍按完整图像大小分配。

替换图片直接写入目标槽，途中断电可能丢失该槽旧图片。更换屏幕几何或图片存储跨度后，旧图槽会失效，需要上传匹配新屏幕的图片。

支持屏型、方向、时间、时区、设备备注和灯效策略保存。备注不改变蓝牙广播名称。屏温在正常刷新时采样，缓存有效期 15 分钟；查询不会唤醒屏幕，无有效数据时显示不可用。
